# MarketFild website

## Opening this on your PC

1. Right-click the zip → **Extract All** → pick a folder.
2. Open the **extracted folder**, not the zip.
3. Double-click `index.html`.

## Pages

| File | Page |
|---|---|
| `index.html` | Home |
| `marketplaces.html` | Amazon, Flipkart, Walmart |
| `quick-commerce.html` | Blinkit, Zepto, Instamart |
| `services.html` | Full service stack |
| `approach.html` | First 90 days + principles |
| `about.html` | About + who we fit |
| `contact.html` | Booking calendar + FAQ |

## Logo files

Traced from your transparent PNG master. Use these, not the original file.

| File | Use it for |
|---|---|
| `logo-mark.svg` | Wordmark, dark. Site header |
| `logo-mark-light.svg` | Wordmark, white. Dark backgrounds |
| `logo.svg` | Full lockup with tagline, dark |
| `logo-light.svg` | Full lockup with tagline, white. Site footer |
| `logo-dark.png` | Transparent PNG, full size. Decks, print, email signature |
| `logo-light.png` | Transparent white PNG, full size |
| `logo-mark.png` / `logo-mark-light.png` | 700px wordmark PNGs. Also used as automatic fallbacks |
| `favicon.png` | Browser tab icon and social avatar |

Brand colours, measured from the logo itself:
- Blue `#0043FB`
- Ink `#090909`

## Editing

Words live in the `.html` files. Colours, fonts and spacing are at the
top of `site.css` under `:root`.
